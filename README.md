# Hamsaveni B S — Personal Portfolio

A responsive, single-page portfolio website based on the supplied resume.

## Run locally
1. Extract the ZIP file.
2. Open the `hamsaveni_portfolio` folder.
3. Double-click `index.html` to preview it in your browser.

## Customize before publishing
- Check the contact details and profile links in `index.html`.
- Add a GitHub/live-demo link for IntelliMin if you have one.
- Add a profile photo if you want one; the hero currently uses a CSS initials illustration.
- Update project descriptions if your implementation has changed.

## Deploy
You can publish this static website with GitHub Pages, Netlify, or Vercel. Upload the three website files (`index.html`, `style.css`, `script.js`) to a GitHub repository, then connect that repository to your hosting provider.
